# Screenshots Directory Guide

This folder contains UI captures and visual previews referenced in the main [`README.md`](../README.md).

## Recommended File Naming

Drop your exported PNG or WebP screenshots into the corresponding subdirectories using these filenames to have them display in the repository README:

### Web Screenshots (`screenshots/web/`)

| Filename | Description | UI Location |
| :--- | :--- | :--- |
| `dispatch-dashboard.png` | Coordinator Triage & Dispatch Dashboard | Web `/operations` or `/dispatch` |
| `recommendation-modal.png` | AI Recommendation Inspection & Action Modal | Web (Approve / Edit / Regenerate / Reject modal) |
| `problem-consolidation.png` | Problems Overview & Related Reports Review | Web `/problems` |
| `crew-management.png` | Municipal Fleet Directory & Status Badges | Web `/crews` |
| `work-orders.png` | Operations Console & Work Order Status Tracker | Web `/work-orders` |

### Mobile Screenshots (`screenshots/mobile/`)

| Filename | Description | UI Location |
| :--- | :--- | :--- |
| `resident-report-gps.png` | Resident Incident Submission with GPS Map & Photo | Mobile Resident Portal (`/resident/report`) |
| `resident-my-reports.png` | Citizen Submitted Reports & Resolution Status | Mobile Resident Portal (`/resident/my-reports`) |
| `crew-squad-status.png` | Crew Leader Readiness Banner & Duty Toggle | Mobile Crew Portal (`/crew/home`) |
| `crew-job-execution.png` | Assigned Missions Queue & Field Execution View | Mobile Crew Portal (`/crew/jobs`) |

> **Tip:** Recommended aspect ratio for web is 16:9 or 16:10. For mobile, vertical mobile screenshots (9:16) look best side-by-side.
